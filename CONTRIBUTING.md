# Contributing

Small, reproducible corrections are welcome. Describe the observed behavior, expected result and a minimal synthetic example. Check open and closed issues and pull requests before starting work. For a scope change, update the related specification and explain the design tradeoff.

Run npm run check with Node.js 22 or newer. Add meaningful tests for changed behavior and preserve existing security boundaries. Report exact validation results, including skipped or preexisting failures. Never include credentials or private project material.

AI-assisted contributions and automated PR submission are permitted when authorized by the account owner. The person submitting the contribution remains responsible for reviewing the complete diff, understanding it, running the checks and disclosing AI assistance in the PR description. No DCO, OCA, assignment or prior discussion is required for a scoped bug fix. Larger features benefit from discussing scope first.
